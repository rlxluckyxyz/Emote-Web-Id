LUCKY EMOTE WEB

1. Extract this ZIP.
2. Open the Lucky-Web-Folder.
3. Install dependency:
   pip install -r requirements.txt
4. Run:
   python app.py
5. Open in your browser:
   http://127.0.0.1:5000

On Android/Termux, install Python first, then run the same commands.
For access from another device on the same Wi-Fi, open:
   http://YOUR-PHONE-IP:5000

The emotes folder contains the images supplied in your ZIP.
The ID is taken from each image filename without its extension.
Example: 909000001.webp -> ID 909000001.
The dashboard shows 50 emotes per page.
